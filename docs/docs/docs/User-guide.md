# User Guide

## As a Requester
1. Open the web app URL
2. Tab **New Request** → fill equipment, category, priority, description
3. Submit → you receive a Work Order ID
4. Tab **Work Orders** → track status of your requests

## As a Technician
1. Tab **Work Orders** → filter by status = Assigned
2. Click **Start** when you begin → status = In Progress
3. Click **Complete** → enter action taken + remarks

## As a Supervisor / Admin
- Assign technicians (via Sheets or extend UI)
- Tab **Dashboard** → KPIs, recurring equipment
- Export: File → Download → CSV from the Requests sheet
